Looks the part up at every vendor you enabled on the Search tab. Prices are shown side by side and never ranked across currencies or between net and VAT-inclusive prices.

Search syntax

Everything works the same on every vendor. Put it in the search box or in More filters.

WriteMeaning
resistor 0603all words (words with digits must appear in the part text)
"thick film"exact phrase
lm358 OR lm324alternatives
-automotive · -"low power"exclude
mfr:ti|onsemi · mfr:=TImanufacturer contains / equals (spelled as the vendor spells it: "Texas Instruments")
pkg:0603 · pkg:=SOIC-8package (bare 0603 means the imperial size)
cat:resistor · mpn:LM358 · code:C25804category, part number, vendor code
lib:basic · is:preferredJLCPCB library class (JLCPCB / LCSC only)
is:instock · is:rohs · has:datasheetflags (not every vendor supports every flag)
stock:>=1000 · price:<0.01numbers; price is the unit price at the quantity you set
res:10k..100k · cap:100n · tol:<=1% · volt:>=50Vattributes with units: 10k = 10kΩ, 100n = 0.1µF
@"Number of Pins":>=8any attribute by its exact name

Good to know

  • Vendors that need an API key show a grey dot until the server has the key. Mouser has no technical attributes at all.
  • DigiKey applies attribute filters server-side inside one leaf category: cat:"Chip Resistor - Surface Mount" res:10k..100k.
  • Sorting orders the results that were read, except where the vendor sorts server-side (DigiKey, TME).
  • Open a result for the full price ladder, all attributes, datasheet and 3D-model download (STEP / OBJ, matched by exact part number).
  • Use Filters on a vendor's result block to see which manufacturers, packages and attribute values exist, and click one to add it.
